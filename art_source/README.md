# Flatworld art sources

Authoritative geometry remains in the TypeScript plane simulation.

`flatworld-planar-materials.blend` is the source material laboratory for the
native town. It is generated by `scripts/blender/build_flatworld.py`, which
bakes the tileable color and normal maps used by the browser renderer.

Native Flatland objects remain coplanar. The older civic-kit file is retained
only as prototype history and is not loaded by the application.
